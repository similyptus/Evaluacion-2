# HU-RH-02 Gestionar contratos y finiquitos

## Historia de usuario

Como encargado de Recursos Humanos, quiero generar contratos y finiquitos asociados a cada trabajador, para administrar correctamente la documentación laboral de Seguridad LTDA.

## Descripción funcional

Esta funcionalidad permite registrar contratos laborales asociados a cada empleado, incluyendo cargo, sueldo, fecha de inicio, tipo de contrato y condiciones laborales. Además, permite registrar información base para finiquitos cuando termina la relación laboral.

## Criterios de aceptación

- El sistema debe permitir asociar un contrato a un empleado.
- El sistema debe registrar fecha de inicio, cargo, sueldo y tipo de contrato.
- El sistema debe permitir registrar fecha de término cuando corresponda.
- El sistema debe permitir generar información base para finiquito.
- El sistema debe mantener historial contractual del trabajador.

## Atributos de calidad relacionados

- Seguridad: los contratos contienen información sensible del trabajador.
- Confiabilidad: los datos laborales deben ser correctos y consistentes.
- Mantenibilidad: el módulo debe permitir nuevos formatos de contrato o finiquito.
- Usabilidad: la información debe poder registrarse de forma clara y ordenada.
