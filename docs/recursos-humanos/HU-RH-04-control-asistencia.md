# HU-RH-04 Controlar asistencia

## Historia de usuario

Como administrador de Recursos Humanos, quiero consultar horas trabajadas, atrasos y ausencias, para controlar la asistencia del personal de Seguridad LTDA.

## Descripción funcional

Esta funcionalidad permite registrar y consultar la asistencia diaria del personal, considerando hora de entrada, hora de salida, atrasos, ausencias y horas trabajadas. La información puede ser consultada por trabajador y rango de fechas.

## Criterios de aceptación

- El sistema debe registrar hora de entrada y salida.
- El sistema debe calcular horas trabajadas.
- El sistema debe identificar atrasos.
- El sistema debe registrar ausencias.
- El sistema debe permitir consultar asistencia por trabajador y rango de fechas.

## Atributos de calidad relacionados

- Confiabilidad: los cálculos de asistencia deben ser correctos.
- Eficiencia: las consultas deben responder rápidamente.
- Usabilidad: la visualización debe ser clara para Recursos Humanos.
- Disponibilidad: la información debe estar accesible para usuarios autorizados.
