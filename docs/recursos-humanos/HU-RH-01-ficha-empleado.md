# HU-RH-01 Registrar ficha de empleado

## Historia de usuario

Como administrador de Recursos Humanos, quiero registrar empleados con sus datos personales, laborales y previsionales, para mantener una ficha completa y actualizada del personal de Seguridad LTDA.

## Descripción funcional

Esta funcionalidad permite registrar y consultar la ficha completa de cada trabajador de Seguridad LTDA. La ficha considera información personal, datos laborales, cargo, centro de costo, contrato, previsión y antecedentes relevantes del empleado.

## Criterios de aceptación

- El sistema debe permitir ingresar datos personales del empleado.
- El sistema debe permitir ingresar datos laborales como cargo, centro de costo y tipo de contrato.
- El sistema debe permitir registrar información previsional.
- El sistema debe validar campos obligatorios.
- El sistema debe permitir consultar la ficha del empleado registrado.

## Atributos de calidad relacionados

- Usabilidad: el formulario debe ser claro e intuitivo para el usuario.
- Seguridad: la información del trabajador debe estar protegida.
- Confiabilidad: los datos registrados deben mantenerse completos y correctos.
- Mantenibilidad: la funcionalidad debe permitir futuras modificaciones.
