# HU-RH-05 Gestionar vacaciones

## Historia de usuario

Como encargado de Recursos Humanos, quiero planificar y controlar vacaciones de los trabajadores, para conocer los días disponibles, utilizados y pendientes dentro de Seguridad LTDA.

## Descripción funcional

Esta funcionalidad permite registrar solicitudes de vacaciones, calcular días hábiles, aprobar o rechazar solicitudes y consultar días usados, pendientes y disponibles por trabajador.

## Criterios de aceptación

- El sistema debe permitir registrar solicitudes de vacaciones.
- El sistema debe calcular días hábiles solicitados.
- El sistema debe mostrar días usados y días pendientes.
- El sistema debe permitir aprobar o rechazar solicitudes.
- El sistema debe generar una ficha individual de vacaciones.

## Atributos de calidad relacionados

- Usabilidad: el flujo de solicitud debe ser fácil de entender.
- Confiabilidad: los días disponibles y usados deben calcularse correctamente.
- Disponibilidad: la información debe estar accesible para el personal autorizado.
- Seguridad: solo usuarios autorizados deben aprobar o rechazar solicitudes.
