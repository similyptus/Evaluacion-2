# HU-RH-03 Registrar licencias médicas

## Historia de usuario

Como encargado de Recursos Humanos, quiero registrar licencias médicas de los trabajadores, para controlar ausencias justificadas y considerarlas en la gestión mensual de Seguridad LTDA.

## Descripción funcional

Esta funcionalidad permite registrar licencias médicas por trabajador, indicando fechas, tipo de licencia, estado y observaciones. El registro permite controlar ausencias justificadas y mantener estadísticas por trabajador o centro de costo.

## Criterios de aceptación

- El sistema debe permitir registrar fecha de inicio y término de la licencia.
- El sistema debe permitir indicar tipo de licencia médica.
- El sistema debe asociar la licencia a un trabajador.
- El sistema debe permitir registrar estado: aprobada, rechazada o pendiente.
- El sistema debe generar historial de licencias por trabajador.

## Atributos de calidad relacionados

- Confiabilidad: las licencias deben registrarse correctamente.
- Seguridad: la información médica debe ser tratada con resguardo.
- Usabilidad: el registro debe ser simple para el encargado de Recursos Humanos.
- Mantenibilidad: el sistema debe permitir nuevos tipos o estados de licencia.
