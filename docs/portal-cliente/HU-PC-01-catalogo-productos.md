# HU-PC-01 Visualizar catálogo de productos

**Historia de Usuario**
Como cliente, quiero visualizar un catálogo de productos, para conocer las opciones disponibles antes de realizar una compra.

**Descripción funcional**
Interfaz principal del Front-Office destinada a los clientes. Muestra de forma atractiva y organizada los productos ofrecidos por Seguridad LTDA, estructurados por categorías con imágenes, descripciones y detalles comerciales.

**Criterios de aceptación**
- El sistema debe mostrar productos por categoría.
- El sistema debe mostrar nombre, descripción e imágenes del producto.
- El sistema debe mostrar información relevante del producto.
- El sistema debe permitir navegar de forma clara entre categorías.

**Atributos de calidad relacionados**
- **Usabilidad:** Navegación intuitiva y diseño atractivo (fácil de usar).
- **Eficiencia:** Tiempos de carga rápidos para las imágenes y datos del catálogo.
