# HU-PC-04 Acceder al portal desde móvil

**Historia de Usuario**
Como cliente, quiero acceder al portal de ventas desde un dispositivo móvil, para realizar consultas y compras desde cualquier lugar.

**Descripción funcional**
Diseño responsivo (Responsive Web Design) aplicado a toda la interfaz del Portal del Cliente. Garantiza que la visualización del catálogo, la navegación y el proceso de compra se adapten perfectamente a las resoluciones de smartphones y tablets.

**Criterios de aceptación**
- El sistema debe adaptarse a pantallas móviles.
- El sistema debe funcionar en navegadores principales.
- El sistema debe mantener navegación clara desde celular.
- El sistema debe permitir consultar productos desde dispositivos móviles.

**Atributos de calidad relacionados**
- **Portabilidad:** Capacidad del software de ejecutarse en distintos entornos y dispositivos.
- **Usabilidad:** Experiencia táctil optimizada para pantallas pequeñas.
