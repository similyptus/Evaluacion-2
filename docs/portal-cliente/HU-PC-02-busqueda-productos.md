# HU-PC-02 Buscar y filtrar productos

**Historia de Usuario**
Como cliente, quiero buscar y filtrar productos, para encontrar rápidamente el producto que necesito.

**Descripción funcional**
Motor de búsqueda y sistema de filtrado avanzado integrado en el Portal del Cliente. Permite acotar los resultados del catálogo utilizando palabras clave, códigos SKU y filtros dinámicos (como categoría o disponibilidad).

**Criterios de aceptación**
- El sistema debe permitir búsqueda por nombre del producto.
- El sistema debe permitir búsqueda por código o palabra clave.
- El sistema debe sugerir resultados mientras el cliente escribe.
- El sistema debe permitir filtrar por categoría o disponibilidad.

**Atributos de calidad relacionados**
- **Eficiencia:** El motor de búsqueda debe responder rápidamente con sugerencias en tiempo real.
- **Usabilidad:** Opciones de filtro claras y accesibles para el usuario.
