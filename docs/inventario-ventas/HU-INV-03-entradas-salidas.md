# HU-INV-03: Registrar entradas y salidas de productos

### Historia de Usuario
Como encargado de bodega, quiero registrar los movimientos de entrada y salida de mercancía, para mantener el inventario actualizado en tiempo real.

### Criterios de Aceptación
- El sistema debe permitir seleccionar el tipo de movimiento (Entrada por proveedor, Salida por venta, Traspaso entre bodegas).
- Cada registro debe capturar la cantidad, fecha, hora y el usuario responsable de forma automática.
- Se debe generar un documento o comprobante digital numerado por cada movimiento exitoso.

### Atributos de Calidad Relacionados (ISO/IEC 25010)
- **Adecuación Funcional:** Automatiza por completo el flujo operacional de existencias físicas en el sistema ERP.
- **Seguridad (Responsabilidad):** Mantiene la trazabilidad exacta e inalterable de qué usuario realizó cada movimiento de stock.
