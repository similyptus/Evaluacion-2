# HU-INV-01: Registrar ficha de producto

### Historia de Usuario
Como encargado de bodega de Seguridad LTDA, quiero registrar productos con sus especificaciones técnicas y códigos alfanuméricos, para mantener un catálogo centralizado y organizado del inventario.

### Criterios de Aceptación:

- Permitir el ingreso de un código alfanumérico único de hasta 20 caracteres.

- Clasificar los productos de forma jerárquica por Grupo y Subgrupo.

- Permitir adjuntar código de barras, fotografía y la ubicación física en bodega.

- Definir los parámetros numéricos de stock mínimo, máximo y reposición.

Atributos de Calidad Relacionados (ISO/IEC 25010)
- **Adecuación Funcional:** Cumple con la totalidad de los requisitos de registro exigidos por el negocio para Seguridad LTDA.
- **Usabilidad:** Diseño intuitivo que minimiza los errores de digitación del bodeguero al ingresar nuevos ítems.
