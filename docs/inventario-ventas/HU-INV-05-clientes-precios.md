# HU-INV-05: Gestionar clientes y listas de precios

### Historia de Usuario
Como ejecutivo comercial, quiero asociar listas de precios diferenciadas a los perfiles de clientes, para automatizar la facturación según los convenios vigentes.

### Criterios de Aceptación
- El sistema debe permitir registrar clientes con su RUT, giro, dirección y contacto.
- Permitir la creación de múltiples listas de precios (Mayorista, Convenio Estado, Cliente General).
- Al generar una cotización o venta, el ERP debe aplicar automáticamente el precio correspondiente al tipo de cliente seleccionado.

### Atributos de Calidad Relacionados (ISO/IEC 25010)
- **Adecuación Funcional:** Mapea de forma exacta las reglas de negocio del módulo comercial de Seguridad LTDA.
- **Eficiencia de Rendimiento:** El cálculo automatizado de descuentos y aplicación de tarifas debe procesarse de manera instantánea.
