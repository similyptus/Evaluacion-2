# HU-PE-05 Consultar licencias médicas

**Historia de Usuario**
Como empleado, quiero consultar mis licencias médicas registradas, para revisar su estado y fechas asociadas.

**Descripción funcional**
Sección dedicada al seguimiento de los reposos médicos del trabajador. Permite ver el historial completo, los estados de tramitación y las fechas involucradas para asegurar el correcto cruce de información con el pago de remuneraciones.

**Criterios de aceptación**
- El sistema debe mostrar licencias por período.
- El sistema debe indicar fecha de inicio y término.
- El sistema debe mostrar estado de la licencia.
- El sistema debe permitir visualizar historial de licencias.

**Atributos de calidad relacionados**
- **Seguridad:** Protección de datos sensibles relacionados con la salud del trabajador.
- **Disponibilidad:** El historial debe estar siempre accesible para consultas.
