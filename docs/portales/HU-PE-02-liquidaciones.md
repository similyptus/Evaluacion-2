# HU-PE-02 Consultar e imprimir liquidaciones

**Historia de Usuario**
Como empleado, quiero consultar e imprimir mis liquidaciones de sueldo, para acceder a mis documentos laborales cuando los necesite.

**Descripción funcional**
Funcionalidad que permite a los colaboradores acceder a un repositorio digital de sus liquidaciones de sueldo históricas y actuales. El módulo genera una vista detallada del documento y ofrece opciones para su descarga en formato PDF o impresión directa.

**Criterios de aceptación**
- El sistema debe mostrar liquidaciones disponibles por mes.
- El sistema debe permitir seleccionar una liquidación específica.
- El sistema debe permitir imprimir o descargar la liquidación.
- El sistema debe restringir la consulta solo al empleado correspondiente.

**Atributos de calidad relacionados**
- **Seguridad:** Privacidad absoluta sobre la información financiera del trabajador.
- **Disponibilidad:** Acceso a los documentos 24/7 sin depender del área de RRHH.
