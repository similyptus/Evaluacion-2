# HU-PE-03 Solicitar vacaciones

**Historia de Usuario**
Como empleado, quiero solicitar vacaciones desde el portal, para enviar mi solicitud de forma rápida al área de Recursos Humanos.

**Descripción funcional**
Módulo transaccional que permite a los empleados gestionar sus feriados legales. Calcula automáticamente los días hábiles seleccionados, contrasta la información con los días disponibles del trabajador y genera un flujo de aprobación hacia su jefatura o RRHH.

**Criterios de aceptación**
- El sistema debe permitir seleccionar fecha de inicio y término.
- El sistema debe calcular los días solicitados.
- El sistema debe mostrar días disponibles y pendientes.
- El sistema debe enviar la solicitud para aprobación.
- El sistema debe mostrar el estado de la solicitud.

**Atributos de calidad relacionados**
- **Eficiencia:** Rapidez en el cálculo de días y gestión del flujo de aprobación.
- **Interoperabilidad:** Correcta comunicación con el módulo de Recursos Humanos (trabajado por el Integrante 1).
