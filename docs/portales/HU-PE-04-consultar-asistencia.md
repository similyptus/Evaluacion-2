# HU-PE-04 Consultar asistencia

**Historia de Usuario**
Como empleado, quiero consultar mi hoja de asistencia, para revisar mis horas de entrada, salida, atrasos y ausencias.

**Descripción funcional**
Herramienta de visualización que muestra el registro de marcaje del trabajador. Permite filtrar por fechas y entrega un resumen claro de las horas trabajadas, facilitando la transparencia entre el empleado y la empresa.

**Criterios de aceptación**
- El sistema debe permitir seleccionar un rango de fechas.
- El sistema debe mostrar horas de entrada y salida.
- El sistema debe mostrar horas trabajadas.
- El sistema debe mostrar atrasos y ausencias.
- El sistema debe permitir consultar solo la información del empleado autenticado.

**Atributos de calidad relacionados**
- **Confiabilidad:** Los datos mostrados deben ser un reflejo exacto e inalterable del reloj control.
- **Usabilidad:** Los filtros de fechas deben ser claros y los resultados fáciles de interpretar.
