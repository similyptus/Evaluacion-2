# HU-PE-01 Actualizar información personal

**Historia de Usuario**
Como empleado, quiero actualizar mi información personal en el portal, para mantener mis datos vigentes dentro del sistema de Recursos Humanos.

**Descripción funcional**
Este módulo proporciona una interfaz de autoservicio dentro del Portal del Empleado que permite al personal de Seguridad LTDA visualizar y editar sus datos personales y de contacto. El sistema se encarga de validar la información ingresada y actualizar la base de datos central de Recursos Humanos.

**Criterios de aceptación**
- El sistema debe permitir visualizar los datos personales del empleado.
- El sistema debe permitir modificar solo los campos autorizados.
- El sistema debe validar campos obligatorios.
- El sistema debe guardar los cambios realizados.
- El sistema debe restringir el acceso solo al empleado autenticado.

**Atributos de calidad relacionados**
- **Seguridad:** Control de acceso estricto; solo el usuario autenticado puede modificar sus propios datos.
- **Usabilidad:** Interfaz intuitiva y fácil de usar para evitar errores en la digitación de datos.
- **Confiabilidad:** Exactitud en la actualización de la base de datos sin pérdida de información.
