# HU-QA-02 Documentar modelos de calidad aplicados

**Objetivo**
Seleccionar y documentar los estándares internacionales de calidad que fundamentarán las metodologías y procesos del proyecto ERP.

**Descripción**
Análisis y aplicación de los marcos de referencia que aseguran que el software sea desarrollado bajo normativas comprobadas, abarcando desde la calidad del producto final hasta la gestión de los procesos del equipo de desarrollo.

**Norma o modelo aplicado**
- ISO/IEC 25010 (Calidad del producto software).
- IEEE 730 (Estándar para Planes de Aseguramiento de Calidad de Software).
- CMMI (Integración de Modelos de Madurez de Capacidades para mejorar procesos).

**Procedimiento**
1. Revisar los estándares requeridos por la evaluación.
2. Redactar cómo la norma ISO/IEC 25010 rige las características del software entregado.
3. Especificar la estructura del Plan de Calidad basándose en IEEE 730.
4. Definir prácticas de mejora continua basadas en CMMI.

**Evidencia esperada**
Sección formal dentro del Plan de Calidad que detalla los modelos y explica su aplicación práctica en el contexto de Seguridad LTDA.
