# HU-QA-05 Crear casos de prueba funcionales

**Objetivo**
Diseñar escenarios de prueba formales para asegurar que las historias de usuario desarrolladas cumplan íntegramente con sus criterios de aceptación.

**Descripción**
Documentación de pruebas estructuradas tipo "Caja Negra" que simulan la interacción del usuario final con el sistema, abarcando todos los módulos principales del ERP web de Seguridad LTDA.

**Norma o modelo aplicado**
Técnicas de diseño de pruebas de caja negra (Equivalencia, Valores Límite) e IEEE 829 (Documentación de pruebas).

**Procedimiento**
1. Tomar cada Historia de Usuario priorizada.
2. Identificar la condición previa o "Entrada".
3. Detallar la "Acción" que ejecutará el usuario.
4. Definir el "Resultado esperado" basado en el Criterio de Aceptación.
5. Registrar el "Estado" (Aprobado/Rechazado) tras la ejecución.
6. Abarcar los módulos: Recursos Humanos, Inventario/Ventas, Portal del Empleado y Portal del Cliente.

**Evidencia esperada**
Matriz de Casos de Prueba (Excel o tabla Markdown) con columnas para Entrada, Acción, Resultado Esperado y Estado, para todas las áreas solicitadas.
