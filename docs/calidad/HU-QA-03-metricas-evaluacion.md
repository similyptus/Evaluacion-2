# HU-QA-03 Definir métricas y métodos de evaluación

**Objetivo**
Establecer los indicadores cuantitativos (métricas) y las metodologías de revisión para medir objetivamente la calidad del desarrollo y del equipo.

**Descripción**
Definición de los KPIs que permitirán monitorear la salud del proyecto durante los sprints, así como la estandarización de cómo se revisará el código y se validarán las historias de usuario antes de darlas por terminadas.

**Norma o modelo aplicado**
Métricas estándar de metodologías ágiles y principios de calidad IEEE.

**Procedimiento**
1. Definir fórmula y meta para la "Métrica de cumplimiento de tareas por sprint".
2. Establecer el registro para la "Métrica de defectos encontrados".
3. Definir la regla de revisión para la "Métrica de pull requests".
4. Documentar el uso de métodos de evaluación: revisión de código entre pares (Pull Requests), pruebas funcionales y el checklist de validación de Criterios de Aceptación.

**Evidencia esperada**
Catálogo de métricas documentado con sus fórmulas y documento descriptivo de los métodos de evaluación aprobados por el equipo.
