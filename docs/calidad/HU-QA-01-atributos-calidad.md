# HU-QA-01 Definir atributos de calidad

**Objetivo**
Establecer y documentar los atributos de calidad esenciales que deben regir el desarrollo del sistema ERP web para Seguridad LTDA.

**Descripción**
Este documento define las características no funcionales críticas para el éxito del proyecto, como la facilidad de uso del sistema (usabilidad), la protección de los datos (seguridad) y la conexión entre módulos (interoperabilidad).

**Norma o modelo aplicado**
ISO/IEC 25010 (Modelo de Calidad de Producto de Software).

**Procedimiento**
1. Analizar los requerimientos del caso de Seguridad LTDA.
2. Identificar los atributos críticos (usabilidad, seguridad, disponibilidad, interoperabilidad, mantenibilidad, confiabilidad y eficiencia).
3. Relacionar cada atributo con módulos específicos (ej. interoperabilidad entre Portales e Inventario).
4. Justificar la inclusión de cada atributo en el Plan de Calidad.

**Evidencia esperada**
Matriz o documento detallado con la lista de atributos, su justificación y su relación con las funcionalidades del sistema.
